# SmartTable (público)

Módulos do SmartTable, userscript do Tampermonkey para o CRM TexCotton.
**Este repositório é um espelho automático** (branch `main`): nada é
editado aqui. Qualquer mudança feita direto neste repositório é apagada na
próxima cópia.

## Instalar (Tampermonkey)

- SmartTable: https://raw.githubusercontent.com/IsaacTexCotton/SmartTable-publico/main/smart-table.user.js
- Ponte opcional WhatsApp Web → CRM: https://raw.githubusercontent.com/IsaacTexCotton/SmartTable-publico/main/integracoes/whatsapp-crm-bridge.user.js

A ponte é um userscript separado: instale-a somente se tiver autorização para essa integração. Após clique explícito, tenta primeiro o telefone visível; se não estiver disponível, pesquisa pela raiz do CNPJ no título da conversa ou pela primeira palavra do nome. Não lê o histórico de mensagens nem envia mensagens.
